# GoFieldwise Brand System

Status: locked baseline for product, website, ads, and sales assets.

## 1) Color System

Primary:
- Gold: `#F5C542`
- Deep Gold: `#D4A017`
- Black: `#0B0F1A`

Secondary:
- Dark Navy: `#121826`
- Slate: `#2A3345`
- Light Gray: `#E5E7EB`

Accents:
- Success Green: `#22C55E`
- Info Blue: `#3B82F6`

Usage rules:
- Gold = brand emphasis, high-value actions, key highlights.
- Dark tones = structure, nav, dashboard surfaces.
- Green = success outcomes (booked jobs, recovered calls, paid invoices).
- Keep contrast strong; never put low-contrast gold text on light backgrounds.

## 2) Typography

Primary UI/product font:
- Inter (fallback: Segoe UI, system sans)

Marketing/headline font:
- Poppins or Montserrat

Rules:
- Headlines: bold, concise, confident.
- Body copy: plain language, readable at mobile sizes.

## 3) Positioning

Not:
- "job management software"

Category statement:
- AI-powered field operations and revenue engine.

Core message:
- GoFieldwise runs your entire field operation, from first call to final payment.

Selected tagline:
- From call to cash, automated.

## 4) Messaging Pillars

Always emphasize:
- AI answers calls.
- AI books jobs.
- AI follows up.
- AI helps get paid faster.

Competitive contrast:
- Position as practical AI automation for small service businesses versus generic software tooling.

## 5) Logo and Icon Rules

Full logo:
- Website, ad creatives, landing pages, partner pages.

Icon only:
- Favicon, app icon, avatar/profile, compact nav contexts.

Small surfaces:
- Under 64px use icon-only mark.

App icon guidance:
- Dark background, centered gold mark, rounded square, no text.

## 6) UI Direction

Target feel:
- Clean, operational, mobile-friendly, high-signal dashboarding.

Rules:
- Dark-first shell elements with gold action emphasis.
- Clear card hierarchy and spacing.
- Surface core numbers early: jobs, response speed, leads, revenue.
- Avoid visual noise and heavy enterprise jargon.

## 7) Marketing Voice

Tone:
- Direct
- Results-focused
- Confident

Copy style:
- Lead with pain and measurable outcome.
- Keep claims concrete and plain-language.

Examples:
- Missed calls are costing you jobs. GoFieldwise answers, books, and follows up automatically.
- More jobs. Less chaos. GoFieldwise.

## 8) Implementation Checklist

Product:
- [ ] Theme tokens match this palette in frontend globals.
- [ ] Core CTA components use gold primary action style.
- [ ] Success states use green consistently.

Website:
- [ ] Hero uses core message + selected tagline.

- [ ] Keep one promise per creative.
